Worth knowing — the "address owner" rule
Under the VRRP standard, if a router's real interface address happens to be identical to the virtual IP, that router is the "IP address owner" and is automatically assigned priority 255 — the ceiling, always outranking any configured priority. That's exactly the third-party router's situation here: 192.168.10.1 was its real gateway address long before the FortiGate showed up, so it became the address owner the moment VRRP was configured. The FortiGate, with a different real address, is a plain configured peer at priority 150.
