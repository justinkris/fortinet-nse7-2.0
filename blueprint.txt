Fortinet NSE 7 — Enterprise Firewall 7.6 Administrator
Exam Blueprint (extracted from NSE7-Exam-Blueprint.pdf)

Status:           Available at Pearson VUE
Time allowed:     70 minutes
Exam questions:   30–40
Scoring:          Pass / fail
Languages:        English, Japanese
Product version:  FortiOS 7.6, FortiManager 7.6, FortiAnalyzer 7.6

Audience:
  Network and security professionals responsible for the design,
  administration, and support of an enterprise security infrastructure
  composed of many FortiGate devices.

================================================================
EXAM TOPICS (with internal curriculum codes used by build.py)
================================================================

1.0  System configuration
     1.1  Implement the Fortinet Security Fabric
     1.2  Configure hardware acceleration on FortiGate
     1.3  Configure different operation modes for an HA cluster
     1.4  Implement enterprise networks using VLANs and VDOMs
     1.5  Explain various use case scenarios of a secure network
          using Fortinet solutions

2.0  Central management
     2.1  Implement central management

3.0  Security profiles
     3.1  Manage SSL/SSH inspection profiles, based on a scenario
     3.2  Use a combination of web filters, application control,
          and ISDB to secure a network
     3.3  Integrate IPS to perform security checks in enterprise networks

4.0  Routing
     4.1  Implement OSPF to route enterprise traffic
     4.2  Implement BGP to route enterprise traffic

5.0  VPN
     5.1  Implement IPsec VPN IKE version 2
     5.2  Implement ADVPN to enable on-demand VPN tunnels between sites
