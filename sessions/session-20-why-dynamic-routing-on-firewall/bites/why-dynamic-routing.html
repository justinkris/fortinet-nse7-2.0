SESSION 20 · BITE · WHY DYNAMIC ROUTING

The Route That Nobody Typed

Five-minute reactivation: static's silence, OSPF's map, BGP's diplomacy, and the AD ladder.

OVERVIEW

One Paragraph

Vaultline's DR site sat healthy for 55 minutes while nobody typed the 20-character static route that fixed everything — because static routes are silent rules that only react to local interface state, and the failure was three hops away with a green local link. Dynamic routing replaces the human: continuous liveness (hellos/keepalives), failure advertisement, automatic reconvergence. Inside one administration, OSPF floods topology facts and every router runs Dijkstra over an identical database, making loops structurally impossible once synchronized. Between administrations, BGP exchanges revocable reachability claims over TCP 179, deliberately slow (keepalive 60s / hold 180s) because a session flap dumps an entire table. When redistribution makes sources compete for one prefix, Administrative Distance arbitrates — and it always sides with proximity to truth.

PROBLEM SOLVED

What Was Actually Missing

  • Not the route — four minutes of typing, trivially known in advance.
  • The watcher — something monitoring continuously, detecting immediately, reacting automatically at 2am.
  • Remote visibility — the local interface stayed green; only a protocol can carry news of a failure you can't see.
MENTAL MODEL

Facts vs Claims

OSPF floods facts ("this link died" — an LSA, forwarded verbatim); every router deletes the edge from its own map and independently recomputes. Disagreement is only possible while databases are momentarily mismatched — which is why reliable flooding exists. BGP exchanges claims ("I can reach these prefixes"), alive only while the session lives, revoked by explicit withdrawal, or flushed wholesale when the hold timer expires.

FAILURE FLOW

The Distance-Vector Loop

A–B–C–D in a line; D's link to X dies. C's stale table answers B; B installs "X via C"; C later believes "X via B." The packet ping-pongs, losing 1 TTL per hop, until TTL=0 → drop + ICMP Time Exceeded. TTL is the fuse, not the fix — it kills the packet, repairs nothing. RIP's band-aids: split-horizon, poison reverse, hold-down timers. OSPF makes the loop impossible instead of suppressed: nobody trusts a neighbor's conclusion, everyone computes from the same facts.

KEY TERMS

Vocabulary Checklist

  • IGP / EGP — inside one administration / between administrations. The boundary is who owns the routers.
  • LSA, LSDB, Dijkstra/SPF — the fact, the shared map, the independent calculation.
  • Withdrawal — BGP's explicit revocation of a previously advertised prefix.
  • Hold timer expiry — flushes every route learned from that peer.
  • Route flapping / route flap damping — the global-churn pathology and its penalty/suppress/half-life countermeasure (see extras-04).
  • Redistribution — deliberately copying routes between protocols; the thing that makes AD matter.

The "why": AD rewards directness. eBGP beats OSPF because a redistributed OSPF copy is stale secondhand news; the live eBGP session is the horse's mouth. AD only fires when two sources offer the same prefix — in clean designs, that means redistribution is in the scenario.
Distractors to expect: "TTL prevents routing loops" (it limits damage, doesn't prevent or fix) · "BGP's slow timers are a weakness" (they're the stability design) · "OSPF routers can compute different paths from the same database" (impossible — only mismatched LSDBs diverge) · "BGP runs on IP like OSPF" (no — TCP 179).
ANALOGY

Whispers vs the Newspaper

Memory hook
Distance-vector is Chinese whispers: conclusions decay hop by hop and two people repeating each other loop forever. OSPF is everyone reading the same newspaper: the correction is printed identically for all, and each reader replans their own commute. BGP is diplomacy between rival nations: formal claims over a formal channel, revocable in writing, deliberately unhurried — because a nervous diplomat who tears up every treaty at the first missed phone call destabilizes the whole world.
TROUBLESHOOTING

Checklist Instincts

  • Green interface + dead path? Local state proves the first hop only — look for missing dynamic routing or path-level health checks.
  • Two OSPF routers "disagreeing"? Suspect a database sync problem (flooding, MTU mismatch, adjacency stuck) — never the math.
  • All routes from one BGP peer vanished at once? That's a session event (hold timer expiry), not many individual withdrawals.
  • OSPF and BGP both offering one prefix? Find the redistribution config before reasoning about anything else.
SELF-TEST

Five Questions

  1. What does dynamic routing replace — and what does it explicitly not replace?
  2. Trace the B/C loop and name the exact mechanism that finally kills the packet. Why is it "the fuse, not the fix"?
  3. What is the only condition under which two OSPF routers in one area compute different answers?
  4. BGP hold timer expires on a peer. What happens to the routing table, and why is 180 seconds a feature rather than a flaw?
  5. Recite the FortiGate AD ladder cold, then explain in one sentence why eBGP outranks OSPF.
