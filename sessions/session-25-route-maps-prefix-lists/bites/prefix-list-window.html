SESSION 25 · BITE · PREFIX LISTS

The Prefix-List Window

Bare = exact. le raises the ceiling. ge raises the floor — and evicts the base prefix.

ONE IDEA

The Base Length Is the Implicit Floor

images/bite-25-prefix-window.png
A vertical prefix-length ruler with three windows — bare, le, and ge — showing how ge evicts the base /24.
Minimalist vertical infographic, cream background, navy and blue. A ruler of prefix lengths from /24 (bottom) to /32 (top). Three side-by-side highlighted windows: "bare /24" = one tick at /24 only; "/24 le 26" = a band from /24 to /26 with /24 labeled "floor — still included"; "/24 ge 26" = a band from /26 to /32 with a red X over /24 and caption "ge raised the floor — the base no longer matches". Elegant serif labels, generous whitespace, no clutter.

A prefix-list entry defines a window on prefix length. Written bare, 198.51.100.0/24 matches exactly the /24 — nothing more specific, nothing broader. The modifiers move the walls: le raises the ceiling (so /24 le 26 = /24 through /26, the base still included), and ge raises the floor — which quietly pushes the base prefix out, because /24 no longer satisfies "at least /26".

EntryWindowBare /24 matches?
/24/24 onlyYes
/24 le 26/24 – /26Yes
/24 ge 26/26 – /32No
The trap: adding ge can exclude the very prefix you wrote. If the question shows ge and asks about the base prefix — the answer is no.
