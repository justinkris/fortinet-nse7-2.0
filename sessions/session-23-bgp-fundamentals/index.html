SECTION 02 · WHY THIS SESSION EXISTS

The Problem We're Solving Today

BGP is a policy protocol, not a topology protocol. NSE7 expects you to read its path attributes the way you'd read a routing decision aloud.

Session goal: Establish an eBGP session on the FortiGate and predict which path it will install when receiving the same prefix from two peers.

Key Concepts

  • Autonomous System (AS), eBGP vs iBGP semantics
  • Best-path order: Weight, LocalPref, AS-path, MED, origin, eBGP>iBGP, IGP cost
  • BGP timers (keepalive, holdtime)
  • FortiGate `config router bgp` essentials
  • When the FortiGate is the BGP speaker (rarely on internet, often on WAN)
