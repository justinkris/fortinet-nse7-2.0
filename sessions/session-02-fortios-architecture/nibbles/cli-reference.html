FortiOS CLI — At a Glance

The five root commands, their purpose, and when to reach for each one
config
Write Config
Only command that modifies the database. Changes persist.
show
Read Config
Explicit changes only. Defaults are invisible. Use full-configuration.
get
Read State
Real-time operational state. Clean admin-friendly summaries.
execute
Do Something
Immediate action. Can be irreversible. Think first.
diagnose
Look Inside
Raw engine internals. Active tests. Deeper than get.

The Three Rules to Never Forget
Rule 1: Always run diagnose debug disable when finished. No exceptions.
Rule 2: show silence on a setting = it's at default. Use show full-configuration to see it.
Rule 3: A successful ping from FortiGate ≠ user traffic through FortiGate is permitted. Different path.
Sniffer tip: Use any as the interface to capture all interfaces simultaneously. Reveals the actual egress path and confirms NAT translation in a single capture.
