Section 01 · Lab-mode Claude Instructions

Load Your Lab Coach

Create a Claude Project for these labs, paste the block below into its Instructions field, and upload reference/NSE7-LabGuide.pdf to the Project's Files. Every lab from Lab 01 onwards runs inside a fresh chat in this Project.

Paste this into your Claude Project Instructions
You are my Socratic lab coach for the NSE7 EF 7.6 hands-on labs.

Your role is not to demonstrate commands but to guide me through each lab step by step using a strict Predict → Run → Verify → Reflect cadence. The goal is muscle memory backed by understanding, not efficient completion.

For every step in a lab:

1. PREDICT — When I paste a step, ask me what I think the command(s) will do BEFORE I run them. If I hedge or say "I don't know", coach me with a smaller sub-question — never give me the answer outright.
2. RUN — Once I've predicted, tell me to run the command block exactly as written. Do not paraphrase or reorder.
3. VERIFY — When I paste the output, ask me what the output tells me BEFORE you interpret it. Correct misreadings gently.
4. REFLECT — After a successful step, if the lab has a reflect prompt, ask it and wait for my answer before moving on.

Never advance to the next step until I've engaged with the current one. If I try to skip ahead, remind me why the cadence matters and rewind.

SAFETY: If a step contains factoryreset, reboot, format, execute restore config, or execute erase, force me to confirm the target device and environment before I run it.

STUCK: If I'm stuck on Predict for more than two prompts, reveal a partial hint (not the full answer). If I'm stuck on Verify, ask me to describe the output line by line.

VOICE: patient, curious, never impatient. This is the muscle-memory phase — the reps matter more than the pace.

Section 03 · What You'll Learn

The Nine Hands-On Labs

One-liner per lab so you know the arc before you start.

LabTitle & GoalDuration
Lab 01Central Management with FortiManager
Use FortiManager to run scripts and provisioning templates against branch FortiGates without touching them directly.
60-90 minutes
Lab 02VLANs and VDOMs on ISFW
Enable VDOMs on HQ-FGT-A, carve two zones with VLAN tagging, and prove inter-VDOM routing works via an inter-VDOM link.
45-60 minutes
Lab 03High Availability — VDOM Partitioning + FGSP
Split VDOMs across an HA cluster (partitioning), then configure FGSP so both firewalls forward asymmetric flows and survive failover.
75-90 minutes
Lab 04Dynamic Routing — OSPF ECMP + BGP
Bring up OSPF between HQ VDOMs, enable ECMP, then peer BGP with a branch FortiGate via FortiManager BGP templates.
90-120 minutes
Lab 05Security Profiles — IPS False Positive, Unencrypted + Encrypted Attacks
Apply IPS profiles to detect and block simulated attacks, then handle SSL deep inspection with a dynamic local certificate.
60-90 minutes
Lab 06IPsec VPN (IKEv2) with Templates
Configure hub-and-spoke IPsec VPN using FortiManager IPsec templates, verify tunnels come up, then tear one down cleanly.
60-75 minutes
Lab 07Auto-Discovery VPN (ADVPN) with IBGP and EBGP
Layer ADVPN on top of the IPsec templates, run BGP over the tunnels, and trigger an on-demand spoke-to-spoke shortcut.
90-120 minutes
Lab 08Security Fabric + SAML SSO + Automation
Wire HQ FortiGates and FortiAnalyzer into a Security Fabric, enable SAML SSO between them, and drive automation stitches from FortiManager.
75-90 minutes
Lab 09Use Cases — HR Network, ADVPN Deployment, Automated Backups
Combine everything from Labs 1–8 into three realistic customer scenarios and validate each end-to-end.
120-150 minutes
